# Workspace Rules: GitHub Auto-Sync

## Automatic GitHub Synchronization
- **Always Sync to GitHub**: Whenever any files in this repository are edited, added, or removed, always stage (`git add -A`), commit with a descriptive commit message, and push (`git push origin main`) to the remote GitHub repository ([skinnybuilder07-dotcom/shankar-portfolio](https://github.com/skinnybuilder07-dotcom/shankar-portfolio)) before concluding the task.
- **Commit Quality**: Use clear, concise commit messages that summarize the exact modifications made.
